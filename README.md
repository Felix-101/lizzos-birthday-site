# For Lizzo, With Love 🎀

A birthday site. Open `index.html` in a browser to preview it. You don't need to build anything.

## Adding content

All the text, photo paths and songs are set in **`data.js`**.

| Put files here     | What it's for                                    | Default names            |
| ------------------ | ------------------------------------------------ | ------------------------ |
| `images/hero/`     | Opening photo of you both (landscape works best) | `us.jpg`                 |
| `images/story/`    | "Where It All Started" photos                    | `1.jpg`, `2.jpg`, …      |
| `images/songs/`    | Spotify / YT Music screenshots (optional)        | any name, set in data.js |
| `images/gallery/`  | Random pictures of you two                       | `1.jpg` … `9.jpg`        |
| `music/`           | Background song                                  | `background.mp3`         |

Until you add a photo, its spot shows a pink striped placeholder.

**iPhone photos:** export them as JPG. Chrome can't display `.HEIC` files.
